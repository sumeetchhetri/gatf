# The seleasy VS Code extension

The extension adds seleasy syntax highlighting, a language server (completion, diagnostics, go-to-definition across `import`ed and `include`d files) and a debugger for `.sel` files.

Install it from the 5.0.0 release asset:

```bash
code --install-extension seleasy-5.0.0.vsix
```

Download `seleasy-5.0.0.vsix` from the [5.0.0 release](https://github.com/sumeetchhetri/gatf/releases/tag/5.0.0) first. Settings, commands and the debugger setup are in the [extension's README](https://github.com/sumeetchhetri/gatf/blob/master/vscode-extension/README.md).
