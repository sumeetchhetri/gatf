GATF now has a website. It is built from the same Markdown files as the `docs/` folder in the repository, so a page
reads the same on GitHub and here, and a change to the docs reaches the site with the next deploy.

<!-- truncate -->

What the site has:

- **Docs**, versioned: `5.0` is the release, `next` is what is on `master`.
- **Search** that runs in your browser. The index is built with the site; there is no search service and no analytics.
- **Downloads** for the installers, the jar, the distribution zip and the VS Code extension, linked to the GitHub
  release assets.
- **Release notes**, from `docs/release-notes/`.
- **seleasy highlighting**, converted from the VS Code extension's grammar, so code looks the same in the editor and on
  the site.

The site is built with Docusaurus from the `website/` folder (`npm ci && npm run build`).
